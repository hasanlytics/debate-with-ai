# 🎙️ Voice Debate AI — বাংলা ভয়েস বিতর্ক

Google Gemini API চালিত আধুনিক বাংলা ভয়েস বিতর্ক ওয়েব অ্যাপ্লিকেশন। আপনি কণ্ঠস্বরে অথবা টাইপ করে AI-র সাথে যেকোনো বিষয়ে সরাসরি প্রাণবন্ত যুক্তিতর্ক করতে পারবেন।

---

## 🚀 কীভাবে নিজের কম্পিউটারে চালাবেন (Local Setup)

খুব সহজে মাত্র ৩টি ধাপে আপনার কম্পিউটারে এই ওয়েব অ্যাপটি চালাতে পারবেন:

### প্রয়োজনীয় সফটওয়্যার:
- **Node.js** (সংস্করণ ১৮ বা তার পরবর্তী) — [nodejs.org](https://nodejs.org) থেকে ইনস্টল করে নিন।

---

### ধাপ ১: ফাইল আনজিপ ও টার্মিনাল ওপেন করুন
ডাউনলোড করা `voice-debate-ai.zip` ফাইলটি আনজিপ (Extract) করুন। এরপর ফোল্ডারের ভেতর ঢুকে টার্মিনাল বা কমান্ড প্রম্পট (CMD / PowerShell / Bash) খুলুন।

### ধাপ ২: ডিপেন্ডেন্সি ইনস্টল করুন
টার্মিনালে লিখুন এবং এন্টার চাপুন:
```bash
npm install
```

### ধাপ ৩: API Key সেট করুন
1. ফোল্ডারে থাকা `.env.example` ফাইলটির একটি কপি বানিয়ে সেটির নাম দিন `.env`।
2. `.env` ফাইলে আপনার ফ্রি Gemini API Key বসান:
```env
GEMINI_API_KEY="আপনার_জেমিনাই_এপিআই_কী_এখানে_দিন"
```
*(ফ্রি Gemini API Key পেতে [aistudio.google.com/apikey](https://aistudio.google.com/apikey) এ যান)*

### ধাপ ৪: অ্যাপটি চালু করুন
টার্মিনালে কমান্ড দিন:
```bash
npm run dev
```

এখন আপনার ব্রাউজারে প্রবেশ করুন:
👉 **`http://localhost:3000`**

## 📱 মোবাইল বা কম্পিউটারে অ্যাপের মতো ইনস্টল করার নিয়ম (PWA)

আপনি কোড ডাউনলোড না করেও সরাসরি ব্রাউজার থেকে এটি ইনস্টল করে চালাতে পারেন:
1. **Google Chrome বা Edge ব্রাউজারে** অ্যাপটির লিংকে যান।
2. ইউআরএল বারের ডানপাশে থাকা **"Install App"** বা অ্যাপের ভেতর থাকা **"অ্যাপ ইনস্টল করুন"** বোতামে চাপুন।
3. এটি আপনার ডেস্কটপ বা মোবাইলের হোম স্ক্রিনে আলাদা একটি নেটিভ অ্যাপের মতো যুক্ত হয়ে যাবে!

---

## 🌐 ইন্টারনেটে বন্ধুদের সাথে শেয়ার করার নিয়ম (Deployment)

প্রজেক্টটি Vercel, Render বা Firebase-এ সম্পূর্ণ ফ্রিতে হোস্ট করতে পারবেন:
1. কোডটি আপনার **GitHub** একাউন্টে আপলোড করুন।
2. **Vercel** অথবা **Render**-এ গিয়ে আপনার GitHub রিপোজিটরি সিলেক্ট করুন।
3. Environment Variables-এ `GEMINI_API_KEY` বসিয়ে দিন।
4. **Deploy** বাটনে চাপলেই আপনি বন্ধুদের দেওয়ার মতো একটি পাবলিক লিংক পেয়ে যাবেন!
